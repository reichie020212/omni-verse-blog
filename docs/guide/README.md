# Omni-Verse Blog — Guide

Two visual walkthroughs of the blog:

- **[Reader's guide](./reader.md)** — for visitors. Browsing the magazine grid, searching, opening posts in the drawer, dark mode, signing in, bookmarks, comments.
- **[Author's guide](./author.md)** — for Red. Scaffolding a new post with `pnpm new-post`, frontmatter quirks, MDX features, draft → publish, cover options.

Screenshots live in [`./screenshots/`](./screenshots/) and are regenerated by [`scripts/capture-guide-screenshots.ts`](../../scripts/capture-guide-screenshots.ts) — see the script's docblock for the prereqs (build the project, start the server with `E2E_TEST=1`, run the script).
